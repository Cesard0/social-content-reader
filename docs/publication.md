# Public package boundaries

This repository is a curated export of a local personal project, not a copy of its workspace or evidence cache.

## Included

- Python package, existing tests, package metadata, and a generic example manifest.
- Portable documentation and a short case study.
- Allowlisted, sanitized status summaries with public source attribution.
- Screenshots of documentation views rendered from those summaries.
- A local-only viewer and its source so the visuals are inspectable.

## Excluded

- Raw videos, audio, frames, captions, full speech transcripts, and model weights.
- Original command logs, downloader metadata, signed URLs, and browser sessions.
- Chat exports, internal notes, skill installations, local paths, hardware details, and account configuration.
- Credentials, cookies, email addresses, and virtual environments.
- Unrelated experiments and personal/work files.

No analytics, remote fonts, trackers, embedded social players, screen capture, microphone access, or camera access are used in the documentation viewer. Source links open the original platform only when followed.

Files are selected explicitly for publication. Ignore rules are a second line of defense, not proof that a workspace is safe to upload. The original evidence cache remains local. Git authorship uses GitHub's private noreply address rather than a personal email.
